# Figurinha

App iOS (SwiftUI) para criar figurinhas e importar no WhatsApp.

1. Suba esta pasta inteira no GitHub.
2. No Codemagic: Add application > escolha o repositório > "Codemagic YAML".
3. Rode o workflow `ipa-sem-assinatura` e baixe o .ipa em Artifacts.
4. Troque `com.seunome` pelo seu identificador em `project.yml` e `codemagic.yaml`.
